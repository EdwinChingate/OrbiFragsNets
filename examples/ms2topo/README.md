# ms2Topo example subset

These unchanged exports come from EdwinChingate/ms2Topo, commit
`58a4aa48cd0f387eb1e2bc27912562581ca39dd2`:

- `ms2Topo_Features_table-0.csv` (complete feature table).
- `Alignedms2Features2026-05-20/Consensus_ms2-spectra_0.csv`.
- `Alignedms2Features2026-05-20/Consensus_ms2-spectra_1.csv`.

Source: https://github.com/EdwinChingate/ms2Topo/tree/58a4aa48cd0f387eb1e2bc27912562581ca39dd2

Select features 0 and 1 when running this subset. Other feature rows have no
bundled consensus spectrum. These are input-format examples, not validated
molecular identifications.

`results/` contains example annotation and diagnostic outputs generated by
the new adapter with default settings. See the repository's VALIDATION.md
for the checks and interpretation limits.
